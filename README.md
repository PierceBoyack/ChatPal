This branch is used for developing an AI assistant model on Windows. The code is roughly the same as the Raspberry Pi version. The greatest difference is in ```textToSpeech.py```. This version uses pyttsx3 for TTS. This was an experiment on my end as I wanted to try out different offline vocoders. Piper TTS is definitely a better choice for TTS than the Windows sapi5 driver.
You can replace this file with the Raspberry Pi version's ```textToSpeech.py``` file for the Piper TTS model.
